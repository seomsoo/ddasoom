## 프로젝트 개요

### 기획 배경

공황장애 진단 인원이 빠르게 증가하면서, 일상에서 불안을 관리할 수 있는 실질적인 도구의 필요성이 커졌습니다.
따숨은 공황 발작을 미리 감지하고, 발작 순간과 평소 훈련을 함께 지원하는 서비스를 목표로 기획되었습니다.

### 프로젝트 목표

갤럭시 워치로 수집한 심박수 데이터를 기반으로 공황 발작을 예측하고,
발작 기록·자가진단·생활습관 데이터를 리포트로 제공해 사용자가 자신의 상태를 객관적으로 파악할 수 있도록 돕습니다.
